# Workflow оркестратора

Этот каталог дополняет единственный канонический [workflow](../docs/workflow.md) правилами координации основной сессии Pi. Здесь нет второй схемы этапов, автоматизации или определений агентов.

## Содержимое

- `orchestrator.md` — правила передачи контекста, безопасного делегирования и фиксации состояния; этапы и переходы не дублируются.

## Связь с остальными частями

- Этапы workflow — в [`docs/workflow.md`](../docs/workflow.md).
- Роли — в [`docs/roles.md`](../docs/roles.md); их определения — в [`agents/`](../agents/).
- Артефакты OpenSpec (этап 4) — по конвенциям [`openspec/`](../openspec/).
- Распределение моделей по ролям — [`docs/model-configuration.md`](../docs/model-configuration.md).
