# Проектные профили (stacks)

Опциональные профили под конкретные стеки/инструменты. **Единственное** место, где могут появиться Java, Spring Boot и подобные допущения.

> **Статус:** на текущем этапе профили **не создаются**. Каталог зарезервирован.

## Принцип

- Ядро blueprint (`rules/`, `workflow/`, `openspec/`) stack-agnostic и не предполагает конкретный стек.
- Профиль подключается **только если** целевой проект ему соответствует (определяется на этапе анализа при установке).
- Профиль может содержать: правила (`AGENTS.md`-фрагмент или отдельные `.md`), навыки (`skills/`), промпты, а также специфичные для стека subagent-инструкции.

## Планируемый профиль

- `stacks/java/` — Java / Spring Boot / Spring Modulith (позже, отдельным этапом).

## Структура профиля (предложение)

```
stacks/<name>/
├── README.md          # что покрывает профиль и когда применять
├── rules.md           # стек-специфичные правила
├── skills/            # навыки стека
└── prompts/           # промпт-шаблоны стека
```
