# Промпт-шаблоны (prompts)

Каталог для Markdown-шаблонов, которые при установке копируются в `.pi/prompts/` и становятся slash-командами.

> **Статус:** на текущем этапе шаблоны **не создаются**. Ниже — конвенции.

## Формат (проверено)

```markdown
---
description: <описание, показывается в автодополнении>
argument-hint: "[focus]"
---
<текст шаблона>
```

- Имя файла → имя команды (`/имя`).
- Подстановки: `$1`, `$@` / `$ARGUMENTS`, `${1:-default}`, `${@:N}`, `${@:N:L}`.
- Аргументы с shell-подобным квотированием.

## Планируемые команды (будущее)

| Команда | Назначение |
|---|---|
| `/blueprint:start` | Запустить workflow с этапа 0 (анализ задачи). |
| `/blueprint:propose` | Перейти к OpenSpec-планированию (этап 2). |
| `/blueprint:install` | Выполнить установку blueprint в проект (этап из `install/`). |

> Окончательный набор — после согласования. Имена с префиксом `blueprint:` для избежания коллизий с командами проекта.
