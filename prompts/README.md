# Промпт-шаблоны (prompts)

Каталог для Markdown-шаблонов, которые при установке копируются в `.pi/prompts/` и становятся slash-командами.

> **Статус:** на текущем этапе шаблоны **не создаются**. Ниже — конвенции.

## Формат (проверено)

```markdown
---
description: <описание, показывается в автодополнении>
argument-hint: "[focus]"
---
<текст шаблона>
```

- Имя файла → имя команды (`/имя`).
- Подстановки: `$1`, `$@` / `$ARGUMENTS`, `${1:-default}`, `${@:N}`, `${@:N:L}`.
- Аргументы с shell-подобным квотированием.

## Планируемые команды (будущее)

| Команда | Назначение |
|---|---|
| `/blueprint:start` | Предложить начать с этапа 1 канонического [workflow](../docs/workflow.md). |
| `/blueprint:propose` | Запросить подготовку OpenSpec (этап 4), сначала проверив завершение анализа/проектирования; не обходить Gate A. |
| `/blueprint:install` | Передать инструкции будущего [сценария установки](../install/scenario.md), не писать файлы до подтверждения плана. |

> Окончательный набор и имена — после согласования. Это раскрытие текста, не исполняемые переходы или установщик. Все `/opsx-…` и blueprint-команды подчиняются тем же Human Gate A/B; команды OpenSpec не дублируются.
