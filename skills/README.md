# Навыки (skills)

Каталог для навыков, которые при установке копируются в `.pi/skills/` целевого проекта.

> **Статус:** на текущем этапе навыки **не создаются**. Ниже — конвенции.

## Формат (проверено)

Каталог с `SKILL.md`:

```markdown
---
name: <lowercase-hyphenated>
description: <что делает и когда применять — определяет авто-выбор навыка>
---

<инструкции>
```

- Навык загружается **по требованию** (по `description`), полный текст не держится в контексте постоянно.
- Опционально: `disable-model-invocation: true` (только через `/skill:name`), `allowed-tools`, `license`, `metadata`.
- Внутри можно ссылаться на `scripts/`, `references/`, `assets/` относительно каталога навыка.

## Когда использовать навык vs prompt vs subagent

- **Skill** — специализированные инструкции + вспомогательные файлы, загрузка по требованию.
- **Prompt template** — переиспользуемый `/`-шаблон без исполняемой логики.
- **Subagent** — изолированный контекст для делегирования этапа workflow.

## Планируемые навыки (будущее)

- `openspec` — работа с OpenSpec CLI (уже существует на пользовательском уровне; потребуется проверить соответствие версии).
- Профильные навыки стеков — в `stacks/<профиль>/skills/`.
