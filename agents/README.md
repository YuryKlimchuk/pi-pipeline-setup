# Определения subagents

Здесь будут лежать определения subagents — Markdown-файлы, которые при установке копируются в `.pi/agents/` целевого проекта.

> **Статус:** на текущем этапе файлы subagents **не создаются**. Ниже — конвенции и план.

## Формат (проверено по исходникам расширения subagent)

Каждый файл — Markdown с frontmatter:

```markdown
---
name: <lowercase-name>
description: <что делает и когда использовать>
tools: read, grep, find, ls, bash          # необязательно, через запятую
model: <модель>                            # необязательно
---

<тело = системный промпт агента>
```

- Агент загружается, если есть `name` и `description`.
- `tools` — список разрешённых инструментов через запятую (если пусто — без ограничений).
- `model` — если не задан, используется модель по умолчанию.

## Конвенции blueprint

1. **Не хардкодить `model`.** Имена моделей в существующем окружении специфичны для пользователя. Blueprint-агенты либо опускают `model` (наследуют), либо берут значение из проектных настроек. *Точный механизм — открытое решение (см. `docs/architecture.md`).*
2. `tools` указывать минимально необходимыми (принцип наименьших привилегий): агенту ревью не нужен `write`.
3. Тело агента должно заканчиваться форматом вывода для передачи контекста следующему шагу (`{previous}`).

## Запланированные агенты (будут реализованы на следующем этапе)

| Имя (рабочее) | Роль | Этап workflow | Режим запуска |
|---|---|---|---|
| `explore` | Исследование кодовой базы, сжатый контекст | 1a | single |
| `proposal` | OpenSpec proposal → specs → design → tasks | 2 | chain (`{previous}`) |
| `implement` | Реализация по согласованным tasks | 4 | single |
| `review` | Независимое ревью изменений | 5 | parallel |
| `test` | Запуск/проверка тестов | 6 | parallel |
| `archive` | Приёмка и архивирование через OpenSpec | 7 | single |

> Окончательные имена и состав — после согласования архитектурных решений. Агент `proposal` переиспользует логику существующего `ops-proposal` (пользовательский уровень), но с командами, выверенными под установленный OpenSpec CLI 1.14.0.
