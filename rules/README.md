# Общие правила

Здесь живут **stack-agnostic** правила — они применимы к любому проекту независимо от языка, фреймворка и инструментов.

## Что здесь размещается

- `AGENTS.md` — контекст-файл с общими правилами. При установке копируется в корень целевого проекта (или в `.pi/`), где Pi загружает его автоматически.
- Дополнительные разделы правил (по мере роста) — отдельными `.md` файлами.

## Что НЕ размещается

- Стек-специфичные правила (Java/Spring/…) → [`stacks/`](../stacks/).
- Workflow оркестратора → [`workflow/`](../workflow/).
- Определения subagents → [`agents/`](../agents/).
- Конвенции OpenSpec → [`openspec/`](../openspec/).

## Правило написания

Каждое правило должно быть проверяемым и не ссылаться на конкретный стек. Если правило применимо только к определённому стеку — оно принадлежит профилю в `stacks/`, а не сюда.
